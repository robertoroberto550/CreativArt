CREATIVART - RENDER + POSTGRESQL

1. Pune toate fisierele proiectului in repository-ul GitHub CreativArt.
2. Render foloseste render.yaml si DATABASE_URL pentru baza PostgreSQL.
3. Schema PostgreSQL este initializata automat din database.sql la prima accesare a site-ului.
4. Dupa deploy, deschide site-ul principal o data; tabelele si produsele demo vor fi create automat daca lipsesc.
5. Apoi deschide /install_admin.php si creeaza primul administrator.
6. Dupa crearea administratorului, elimina install_admin.php din repository (recomandat).
7. Site: /   Admin: /admin/   Cont client: /account.php

IMPORTANT: Nu publica DATABASE_URL si nu pune parole in repository.
