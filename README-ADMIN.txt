CREATIVART - ADMIN PENTRU RENDER/POSTGRESQL

1. În GitHub, creează folderul admin în rădăcina proiectului.
2. Încarcă în el toate fișierele din folderul admin din această arhivă.
3. Fă Commit changes. Render va redeploya automat.
4. Dacă nu ai creat încă administratorul, deschide /install_admin.php.
5. După creare, autentificarea este la /admin/login.php sau /admin/.
6. Pentru securitate, elimină install_admin.php după ce ai creat primul administrator.

Panoul folosește ../db.php și baza PostgreSQL existentă.
